# 📔 Personal Journal App

A beautiful and intuitive iOS journal application built with Swift and Core Data. Keep track of your thoughts, ideas, and daily experiences with this elegant and user-friendly app.

![Swift Version](https://img.shields.io/badge/Swift-5.0-orange.svg)
![Platform](https://img.shields.io/badge/Platform-iOS-blue.svg)
![License](https://img.shields.io/badge/License-MIT-lightgrey.svg)

## ✨ Features

- 📝 Create, read, update, and delete journal entries
- 📅 Automatic date tracking for each entry
- 💾 Offline storage using Core Data
- 🔍 Clean and modern user interface
- 📱 Native iOS experience
- 🎨 Beautiful typography and layout
- ⚡ Fast and responsive performance

## 🚀 Getting Started

### Prerequisites

- Xcode 13.0 or later
- iOS 15.0 or later
- Swift 5.0 or later

### Installation

1. Clone the repository
```bash
git clone https://github.com/yourusername/personal-journal-app.git
```

2. Open the project in Xcode
```bash
cd personal-journal-app
open JournalApp.xcodeproj
```

3. Build and run the project in Xcode

## 🛠️ Usage

### Creating a New Entry
1. Tap the + button in the top-right corner
2. Enter a title for your journal entry
3. Write your content in the text view
4. Tap Save to store your entry

### Editing an Entry
1. Tap on any entry in the list
2. Modify the title or content
3. Tap Save to update your changes

### Deleting an Entry
1. Swipe left on any entry in the list
2. Tap Delete to remove the entry

## 🏗️ Architecture

The app follows a clean architecture pattern with the following components:

- **Core Data**: For persistent storage of journal entries
- **MVC Pattern**: For organizing the code structure
- **Auto Layout**: For responsive UI design
- **Navigation Controller**: For managing view transitions

## 📦 Dependencies
